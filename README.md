# Nod app testing results

Прикрепил два обезличенных JSON-файла для GitHub: ```sales-bot-hub.public.n8n.json``` с ИИ-разбором и ```sales-report.public.n8n.json``` с разбором по правилам. Оба сделаны из актуальных версий n8n. Оригиналы не менял, ничего не публиковал.

В копиях нет привязок к credentials, Telegram ID и имени бота, адреса n8n или ссылки на частную таблицу. Исходные примеры заменены вымышленными. По умолчанию Telegram и чтение и запись в Google Sheets отключены, а пустой список доступа блокирует все сообщения.

После импорта укажите разрешённый Telegram ID, подключите своего бота и Google Sheets, замените заглушку ID таблицы в обоих узлах. В ИИ-версии также настройте подключение к модели. Инструкция и заголовки листа есть в заметке внутри каждого файла. Реальные значения указывайте только в приватной копии.

Оба JSON читаются, связи сохранены, параметры узлов проходят проверку n8n, а пустой список доступа отклоняет сообщения в локальной проверке.
